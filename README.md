# Noon Wild

Website for Noon Wild (noonwild.com), luxury exploration travel. An affiliate of Noon Travel.

- Built with [Astro](https://astro.build). Hosted on Netlify.
- Stories live in `src/content/stories/`. See `STORY-GUIDE.md` for how to publish.
- Trip inquiries arrive through the form at `/plan/` (Netlify Forms).

```bash
npm install
npm run dev     # local preview at http://localhost:4321
npm run build   # production build into dist/
```
